> Showroom digital e catálogo interativo desenvolvido para a **Unilar Móveis**, composto por uma Vitrine para clientes e um Painel Administrativo para gestão de produtos.

---

## 🎯 Objetivo

Este projeto simula um cenário real onde uma loja de móveis necessita de uma presença digital visualmente impactante, mas com autonomia para gerenciar seu próprio catálogo.

O foco técnico é o desenvolvimento **Full Stack**, criando uma solução onde o dono da loja possa cadastrar seus móveis e o cliente possa visualizá-los em uma interface moderna.

## 🚀 Funcionalidades

### 🛒 Área do Cliente (Showroom)
* **Galeria Visual:** Apresentação elegante dos móveis com foco nas imagens.
* **Filtros de Catálogo:** Navegação intuitiva por categorias (Sala, Quarto, Cozinha).
* **Detalhes do Produto:** Página dedicada com especificações e fotos detalhadas.
* **Contato Direto:** Integração para contato via WhatsApp facilitando a negociação.

### ⚙️ Área Administrativa (Admin)
* **Acesso Restrito:** Área protegida para gestores da loja.
* **Gestão de Produtos:** Interface para adicionar novos móveis, editar preços e descrições.
* **Upload de Fotos:** Sistema para enviar e armazenar as imagens dos produtos.
* **Controle de Exibição:** Opção para ocultar ou destacar produtos no site.
